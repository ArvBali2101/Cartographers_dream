# MAP

MAP is a Godot 4 top-down psychological / eldritch horror speedrunning prototype.

Run `Main.tscn` in Godot 4.

Controls:

- `WASD` or arrow keys — move
- `Shift` — sprint
- `E`, `Space`, or `Enter` — advance cutscenes
- `F2` — show/hide the speedrun timer
- `Escape` — return to the title screen

The prototype follows the full structure: jungle expedition, drowned sea map, nightmare map, ending, and post-ending sting.

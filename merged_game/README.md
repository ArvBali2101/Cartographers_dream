# Cartographer's Dream - active game

Import this folder's `project.godot` in Godot 4.7 and press F5. On the original workspace computer, use the parent `RUN_MAP.bat`.

Playable order: The Drowned Chart (sea), The Survey (jungle), The Hollow (3D cave), Waking (3D labyrinth). Animated intro, connecting scenes, god-lore evidence, adaptive audio, keys, ward stones and escape/loss endings are included. Timer display is optional and off by default.

WASD moves, Shift sprints, mouse looks in 3D, E/Space interacts, Tab opens the map, Esc pauses. Select keys with 1/2/3 or the mouse wheel. Papers pause gameplay: use Next/Previous and Finish reading; E/Space/Esc also closes them.

See the parent README and SUBMISSION for handoff, `docs/REVISION_NOTES.md` for research and changes, and `docs/ORIGINAL_README.md` for historical author/development notes. Some historical descriptions predate the current revision. Source is included; there is no standalone exported executable in this repository.
